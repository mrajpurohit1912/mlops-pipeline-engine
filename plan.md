# Project
Build Dynamic ML/AI ops pipeline for any kind of dataset.which can process load data from different sources and different kind of dataset(structured/unstructured).
it should do data validation , data cleaning, Exploratory Data Analysis,training and validating different models and selecting best models out of the result.
should be able to save artifact at each stage and generate a report. and all these should be as per industry standard and dynamic should work on all kind of datasets

# Functional Requirements
1. load different kind of dataset(structured/unstructured) from different sources
2. validate dataset
3. data cleaning
4. exploratory data analysis
5. features engineering
6. training on different models
7. validating results of different models and selecting the best one
8. saving artifacts at each stage
9. generating a report
